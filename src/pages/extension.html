浏览器扩展

MediaFlow 浏览器扩展

浏览器里的采集助手：解析当前页视频链接、扫描页内媒体、批量抓列表，一键发到本机 MediaFlow 下载队列。

在 Chrome 应用商店安装

Official companion extension · source code is not included in this repository

它能做什么

解析并发送链接

自动识别当前页视频地址，一键发到桌面端「媒体下载」队列。

扫描本页媒体

扫描页面可下载资源，勾选后批量发送，不限单一播放页。

批量采集 / 滚动抓取

主页、列表页自动滚动收集多条；可设日期与关键词筛选。

多站点适配

内置 TikTok / 抖音 / Instagram / X 等适配，其它站点走通用媒体发现。

Cookie 同步

把浏览器登录态同步给桌面端，减少年龄限制、登录墙下载失败。

右键 / 悬浮 / 快捷键

右键菜单发送、视频页悬浮面板、可自定义快捷键，采集更快。

剪贴板监听

可选：自动识别剪贴板里的视频链接，方便从别处复制过来发送。

历史与增量

记录已发送内容；智能增量可跳过已采集视频，避免重复。

快速开始

  1. 1 安装扩展并固定到工具栏
  2. 2 打开 MediaFlow 桌面端（完全免费，无需激活）
  3. 3 打开视频页：点「发送到 MediaFlow」或「扫描本页」
  4. 4 列表页用「批量采集」；登录墙内容先「同步 Cookie」
  5. 5 回到桌面端「媒体下载」查看队列与进度

使用提示

  • 发送前请保持桌面端已打开，否则扩展无法投递任务。
  • Cookie 同步需在桌面端开启互联/局域网服务（端口 8765）。
  • 部分站点需先在浏览器登录，再同步 Cookie 后下载更稳。
  • 非专用适配站点仍可通过「扫描本页媒体」发现可下载资源。

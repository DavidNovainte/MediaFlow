# Security Policy

## Supported versions

Security fixes are applied to the latest Community release line when feasible.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for sensitive reports.

Email: mediaflow.service@gmail.com

Include:

- Description and impact
- Reproduction steps
- Affected version / commit

We will acknowledge receipt and work on a fix or mitigation as appropriate.

## Secrets

Never commit API tokens, private keys, R2 credentials, or webhook secrets.

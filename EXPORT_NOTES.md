# Community export notes

Generated by `npm run export:community` from the full MediaFlow tree.

## Local dev

```bash
cd mediaflow-community
# node_modules was preserved from previous export
npm run dev
```

## Binaries

- `bin/` is linked to the full product binary folder for local testing (not for public git).

## Flags

- `--clean` — wipe output including `node_modules` / `.git`
- `--no-bin-link` — do not create a local `bin/` link
- `--out <dir>` — custom output directory

## Public release

1. Confirm no secrets (`*.pem`, `r2-config.js`, telemetry tokens)
2. Do **not** commit linked `bin/` or `node_modules/`
3. Push only the Community tree to GitHub
4. Set website `pricing.json` → `communityGithub` to your public repo URL
